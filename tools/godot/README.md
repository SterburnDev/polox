# tools/godot

Portable Godot 4.7.2-stable lives here (not committed to git):

- `Godot_v4.7.2-stable_win64.exe`: the engine (used by `run.bat`)
- `Godot_v4.7.2-stable_win64_console.exe`: console variant (used by `check.bat`)

Get them with `tools\get_godot.bat`, or download `Godot_v4.7.2-stable_win64.exe.zip`
from https://godotengine.org/download/archive/4.7.2-stable/ (or the GitHub release
https://github.com/godotengine/godot/releases/tag/4.7.2-stable) and unzip both files here.
